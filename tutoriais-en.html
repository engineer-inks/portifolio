Mathematical & Statistical Tutorials

Detailed theoretical foundation and practical guide on synthetic data engineering, copula theory, and Monte Carlo sampling applied to Credit Risk (IFRS 9).

1. Sklar's Theorem (1959) and Marginal Decomposition

The Challenge in Financial Data

In traditional banking modeling, we encounter variables that follow completely heterogeneous distribution families. Income has a heavy right tail (modeled by a Log-Normal or Pareto distribution), the Credit Score is bounded between limits (modeled by a Beta or Truncated Normal distribution), and the Limit Utilization Rate concentrates near the extremes.

Attempting to model this mass of data using a standard Multivariate Normal distribution fails severely, as it distorts the individual asymmetries of the variables. This is exactly where Sklar's Theorem comes in.

Mathematical Formulation

Proposed by Abe Sklar in 1959, the theorem states that any multivariate joint Cumulative Distribution Function (CDF) $H(x_1, \dots, x_d)$ of a random vector $X = (X_1, \dots, X_d)$ can be written in terms of its marginal distributions $F_i(x_i) = P(X_i \le x_i)$ and a Copula function $C$:

$$H(x_1, x_2, \dots, x_d) = C\left(F_1(x_1), F_2(x_2), \dots, F_d(x_d)\right)$$
The Probability Integral Transform (PIT):

For any continuous random variable $X_i$ with CDF $F_i$, the transformed variable $U_i = F_i(X_i)$ strictly follows a Uniform distribution on the interval $[0, 1]$. The copula $C(u_1, \dots, u_d)$ is, therefore, a multivariate joint distribution defined on the unit hypercube $[0, 1]^d$ whose marginals are perfectly uniform.

Application in Credit Risk

Sklar's Theorem gives us the freedom to independently fit the best marginal distribution for each customer attribute (e.g., testing Kolmogorov-Smirnov fit for Income) and then "glue" all variables together, preserving the dependency structure through the copula.

2. Gaussian Copulas and Correlation Injection

Definition and Mapping Space

The Gaussian Copula is constructed from the multivariate normal distribution. It acts as a bridge between the uniform space $[0, 1]^d$ and the standard normal space $\mathcal{N}(0, I)$.

$$C_R(u_1, u_2, \dots, u_d) = \Phi_R\left(\Phi^{-1}(u_1), \Phi^{-1}(u_2), \dots, \Phi^{-1}(u_d)\right)$$

Where:

  • $\Phi^{-1}$: Is the quantile function (inverse CDF) of the Standard Univariate Normal $\mathcal{N}(0, 1)$.
  • $\Phi_R$: Is the Cumulative Distribution Function (CDF) of a Multivariate Normal with zero mean and correlation matrix $R \in \mathbb{R}^{d \times d}$.
  • $u_i \in [0, 1]$: Are the cumulative probabilities originating from the model's marginal distributions.

How Correlation is Preserved

The algorithm temporarily transforms the uniform data $u_i$ into normal quantiles $z_i = \Phi^{-1}(u_i)$. In the normal domain, the matrix $R$ imposes the linear Pearson correlation between the variables. When we convert these values back to the original domain of the credit variables, the monotonic Rank correlation (Spearman / Kendall) is consistently preserved.

3. Monte Carlo Simulation via Cholesky Decomposition

The Step-by-Step Sampling Algorithm

To generate $N$ rows of synthetic customer data while ensuring the dependency matrix $R$, we execute four chained steps:

  1. Independent Generation: We draw a $d$-dimensional random vector $\epsilon \sim \mathcal{N}(0, I)$, where each component is orthogonal and independent.
  2. Cholesky Factorization: We decompose the symmetric and positive-definite correlation matrix $R$ into a lower triangular matrix $L$, such that $R = L \cdot L^T$.
  3. Correlation Injection: We multiply the independent vector by the triangular matrix:
    $$Z = L \cdot \epsilon \quad \implies \quad \text{Var}(Z) = E[L\epsilon \epsilon^T L^T] = L \cdot I \cdot L^T = R$$
  4. Uniform Transformation and Marginal Inversion: We map the correlated vector $Z$ to the uniform space $U = \Phi(Z)$ and apply the actual inverse CDFs $F_i^{-1}(U_i)$ to obtain the final values in the correct scale (Income, Score Points, etc.).

Practical Python Implementation

Below is the complete script implementing the mathematical pipeline using numpy and scipy.stats: 

import numpy as np
from scipy.stats import norm, lognorm, beta

# 1. Define number of samples and Correlation Matrix R (Income x Score)
N = 10000
R = np.array([
    [1.00,  0.55],  # Positive correlation between Income and Score
    [0.55,  1.00]
])

# 2. Cholesky Decomposition
L = np.linalg.cholesky(R)

# 3. Generate independent Gaussian noise and apply correlation
Z_indep = np.random.normal(size=(N, 2))
Z_corr = Z_indep @ L.T

# 4. Transform to Uniform [0, 1] via standard Normal CDF
U = norm.cdf(Z_corr)

# 5. Marginal Inversion for Real Credit Distributions
# Income ~ Log-Normal (s=0.6, scale=exp(8.5) -> mean ~ 6,000)
renda_sintetica = lognorm.ppf(U[:, 0], s=0.6, scale=np.exp(8.5))

# Score ~ Beta (a=5, b=2 -> values between 0 and 1000)
score_sintetico = beta.ppf(U[:, 1], a=5, b=2) * 1000

print("Synthetic Dataset Successfully Generated!")
print(f"Observed Correlation: {np.corrcoef(renda_sintetica, score_sintetico)[0,1]:.4f}")
