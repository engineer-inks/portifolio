Motor de Risco & Dados Sintéticos IFRS9

Credit Risk / Machine Learning

Arquitetura para geração de dados financeiros sintéticos mantendo estruturas de dependência complexas entre variáveis de crédito. A solução viabiliza o treinamento de modelos preditivos (PD, LGD, EAD) sem violação de dados sensíveis ou gargalos de amostragem histórica.

Fundamentos Matemáticos

  • Cópulas Gaussianas e matrizes de correlação
  • Teorema de Sklar para marginais não-paramétricas
  • Simulação de Monte Carlo com Decomposição de Cholesky

Engenharia & Cloud

  • Pipeline unificada em Python e PySpark (Lakehouse)
  • Dados estruturados no formato colunar (Parquet)
  • Pronto para integração Serverless em Nuvem
