Tutoriais Matemáticos & Estatísticos

Fundamentação teórica detalhada e guia prático sobre a engenharia de dados sintéticos, teoria das cópulas e amostragem de Monte Carlo aplicadas ao Risco de Crédito (IFRS9).

1. Teorema de Sklar (1959) e Decomposição Marginal

O Desafio em Dados Financeiros

Na modelagem bancária tradicional, deparamo-nos com variáveis que seguem famílias de distribuições completamente heterogêneas. A Renda possui cauda longa assimétrica à direita (modelada por uma distribuição Log-Normal ou Pareto), o Score de Crédito é confinado entre limites (modelado por uma distribuição Beta ou Normal Truncada), e a Taxa de Utilização de Limite concentra-se perto dos extremos.

Tentar modelar essa massa de dados através de uma distribuição Normal Multivariada padrão falha gravemente, pois distorce as assimetrias individuais das variáveis. É exatamente aqui que entra o Teorema de Sklar.

A Formulação Matemática

Proposto por Abe Sklar em 1959, o teorema estabelece que qualquer Função de Distribuição Acumulada (CDF) conjunta multivariada $H(x_1, \dots, x_d)$ de um vetor aleatório $X = (X_1, \dots, X_d)$ pode ser escrita em termos de suas distribuições marginais $F_i(x_i) = P(X_i \le x_i)$ e de uma função Cópula $C$:

$$H(x_1, x_2, \dots, x_d) = C\left(F_1(x_1), F_2(x_2), \dots, F_d(x_d)\right)$$
A Transformada do Integral de Probabilidade (PIT):

Para qualquer variável aleatória contínua $X_i$ com CDF $F_i$, a variável transformada $U_i = F_i(X_i)$ segue estritamente uma distribuição Uniforme no intervalo $[0, 1]$. A cópula $C(u_1, \dots, u_d)$ é, portanto, uma distribuição conjunta multivariada definida no hipercubo unitário $[0, 1]^d$ cujas marginais são perfeitamente uniformes.

Aplicação em Risco de Crédito

O Teorema de Sklar nos dá a liberdade de ajustar de forma independente a melhor distribuição marginal para cada atributo do cliente (ex: testar ajustamento Kolmogorov-Smirnov para a Renda) e, posteriormente, "colar" todas as variáveis preservando a estrutura de dependência através da cópula.

2. Cópulas Gaussianas e a Injeção de Correlação

Definição e Espaço de Mapeamento

A Cópula Gaussiana é construída a partir da distribuição normal multivariada. Ela atua como uma ponte entre o espaço uniforme $[0, 1]^d$ e o espaço normal padrão $\mathcal{N}(0, I)$.

$$C_R(u_1, u_2, \dots, u_d) = \Phi_R\left(\Phi^{-1}(u_1), \Phi^{-1}(u_2), \dots, \Phi^{-1}(u_d)\right)$$

Onde:

  • $\Phi^{-1}$: É a função quantil (inversa da CDF) da Normal Padrão Univariada $\mathcal{N}(0, 1)$.
  • $\Phi_R$: É a Função de Distribuição Acumulada (CDF) de uma Normal Multivariada de média zero e matriz de correlação $R \in \mathbb{R}^{d \times d}$.
  • $u_i \in [0, 1]$: São as probabilidades acumuladas provenientes das distribuições marginais do modelo.

Como a Correlação é Preservada

O algoritmo transforma temporariamente os dados uniformes $u_i$ em quantis normais $z_i = \Phi^{-1}(u_i)$. No domínio normal, a matriz $R$ impõe a correlação de Pearson linear entre as variáveis. Quando convertemos esses valores de volta para o domínio original das variáveis de crédito, a correlação monotônica de Rank (Spearman / Kendall) é preservada de forma consistente.

3. Simulação de Monte Carlo via Decomposição de Cholesky

O Algoritmo de Amostragem Passo a Passo

Para gerar $N$ linhas de dados sintéticos de clientes garantindo a matriz de dependência $R$, executamos quatro etapas encadeadas:

  1. Geração Independente: Sorteamos um vetor de números aleatórios $d$-dimensional $\epsilon \sim \mathcal{N}(0, I)$, onde cada componente é ortogonal e independente.
  2. Fatoração de Cholesky: Decompomos a matriz de correlação simétrica e positiva definida $R$ em uma matriz triangular inferior $L$, tal que $R = L \cdot L^T$.
  3. Injeção de Correlação: Multiplicamos o vetor independente pela matriz triangular:
    $$Z = L \cdot \epsilon \quad \implies \quad \text{Var}(Z) = E[L\epsilon \epsilon^T L^T] = L \cdot I \cdot L^T = R$$
  4. Transformação Uniforme e Inversão Marginal: Mapeamos o vetor correlacionado $Z$ para o espaço uniforme $U = \Phi(Z)$ e aplicamos as CDFs inversas reais $F_i^{-1}(U_i)$ para obter os valores finais na escala correta (R$ de Renda, Pontos de Score, etc.).

Implementação Prática em Python

Abaixo está o script completo que implementa o pipeline matemático utilizando numpy e scipy.stats: 

import numpy as np
from scipy.stats import norm, lognorm, beta

# 1. Definir número de amostras e Matriz de Correlação R (Renda x Score)
N = 10000
R = np.array([
    [1.00,  0.55],  # Correlação positiva entre Renda e Score
    [0.55,  1.00]
])

# 2. Decomposição de Cholesky
L = np.linalg.cholesky(R)

# 3. Gerar ruído Gaussiano independente e aplicar correlação
Z_indep = np.random.normal(size=(N, 2))
Z_corr = Z_indep @ L.T

# 4. Transformar para Uniforme [0, 1] via CDF Normal padrão
U = norm.cdf(Z_corr)

# 5. Inversão Marginal para as Distribuições Reais de Crédito
# Renda ~ Log-Normal (s=0.6, scale=exp(8.5) -> média ~ R$ 6.000)
renda_sintetica = lognorm.ppf(U[:, 0], s=0.6, scale=np.exp(8.5))

# Score ~ Beta (a=5, b=2 -> valores entre 0 e 1000)
score_sintetico = beta.ppf(U[:, 1], a=5, b=2) * 1000

print("Base Sintética Gerada com Sucesso!")
print(f"Correlação Observada: {np.corrcoef(renda_sintetica, score_sintetico)[0,1]:.4f}")
